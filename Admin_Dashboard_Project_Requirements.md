# 🧩 Admin Dashboard Project

## 📋 Assignment Overview

This project is part of your **CSS Grid practice** and focuses on building a responsive admin dashboard layout using HTML and CSS.  
You’ll apply **Grid properties**, **nested grids**, and **structured layout design** principles to create a professional-looking interface.

---

## 🚀 Step 1: Setup and Planning

1. **Initialize a Git repository**

   - Create a new folder for your project.
   - Run `git init` and link your remote repository.
   - Make your initial commit once setup is complete.

2. **Base File Structure**

   ```
   /dashboard-project
   ├── index.html
   ├── style.css
   └── README.md
   ```

3. **Setup HTML & CSS Links**

   - Add dummy content in your `index.html` and link the CSS file to confirm everything works correctly.

4. **Review Design File**
   - Download and inspect the design reference.
   - Note the layout sections: sidebar, header, and main content.

---

## 🧱 Step 2: Layout Structure

1. **HTML Layout**

   - Create containers for:
     - `header`
     - `sidebar`
     - `main-content`

2. **CSS Grid Setup**
   - Apply grid properties in your CSS:
     - Use `display: grid`
     - Define rows and columns
     - Ensure the layout matches the reference structure

---

## 🧩 Step 3: Nested Grids

Take one section at a time and build nested grids:

### Sidebar

- Create grids for:
  - Branding section
  - Navigation section

### Header

- Create grids for:
  - Search bar
  - User info
  - Buttons

### Main Content

- Create grids for:
  - Projects
  - Announcements
  - Trending items

💡 _Use dummy text and placeholder images while building to visualize layout and spacing._

---

## 🎨 Step 4: Gather Assets & Style

1. **Icons**

   - Download icons from [Material Design Icons](https://materialdesignicons.com/)

2. **Fonts**

   - Use [Google Fonts](https://fonts.google.com/) — the design uses **Roboto** (or choose your own)

3. **Styling**
   - Add color, spacing, and typography styles
   - Experiment with hover states, shadows, and borders
   - Use temporary background colors or outlines to visualize grid areas

---

## 💡 Step 5: Helpful Tips

- Use `fr` units or a mix of `px` and `fr` for grid sizing.
- Add `border` or `background-color` temporarily to debug layout alignment.
- You can make your design **responsive** (optional).
- Your goal isn’t pixel-perfect replication — focus on **clean layout and structure**.
- Don’t forget to:
  - Commit your progress regularly.
  - Push your final code to GitHub.
  - Use **GitHub Pages** to publish your live project.

---

## 🧭 Deliverables

- **HTML**: Structured semantic layout
- **CSS**: Grid-based layout with nested sections
- **Design**: Styled dashboard with typography and icons
- **GitHub**: Repository with commits and a live demo link
