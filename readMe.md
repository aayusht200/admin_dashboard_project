# Admin Dashboard Project

## Overview

This is a responsive **Admin Dashboard** web interface built with **HTML** and **CSS**. It is designed to manage projects, view announcements, and track trending items in a visually clean and organized layout.

The dashboard features:

- A **sidebar** with navigation links.
- A **header** with search functionality, profile, notifications, and action buttons.
- A **project grid** displaying project cards with icons for favorite, view, and GitHub links.
- A **right column** for announcements and trending items.

---

## Features

- **Responsive Layout:** Grid-based design for a modern dashboard look.
- **Sidebar Navigation:** Quick access to Dashboard, Home, Profile, Messages, History, Tasks, Community, Settings, Support, and Privacy.
- **Project Cards:** Display key project information with interactive icons.
- **Announcements:** Keep users updated with recent notifications.
- **Trending Section:** Highlight popular or noteworthy items.
- **Search Functionality:** Integrated search bar in the header.
- **Profile Section:** Displays logged-in user info and avatar.
- **Custom Styling:** Smooth, professional design using CSS variables for easy theming.

---

## Technologies Used

- **HTML5**
- **CSS3** (Grid & Flexbox)
- **CSS Variables** for consistent spacing and styling

## How to Run

1. **Clone the repository**

```bash

```

2. **Navigate to the project folder**

```bash
cd admin_dashboard_project
```

3. **Open `index.html` in a web browser**

- Double-click `index.html` or open it with your preferred browser.
